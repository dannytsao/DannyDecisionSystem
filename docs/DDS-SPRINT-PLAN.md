## 執行規則

- 一次只進行一個 Sprint。
- 每個 Sprint 只追求表格中的 Outcome。
- 未通過 Stop condition，不進入下一個 Sprint。
- 新想法先放 Proposal，不插隊。
- 只有實際使用或可靠事後證據發現矛盾、重要缺口、安全問題或 Agent 相容問題，才修改 DDS 核心治理。
